# Resilient and Explainable Cyber-Physical Defense Against Advanced False Data Injection Attacks

LaTeX source and publication figures for a manuscript proposing a generative-AI-augmented, multi-agent deep reinforcement learning framework for detecting and mitigating false data injection attacks (FDIAs) in cyber-physical power systems.

## Contents

- `main.tex` — primary IEEE-style manuscript
- `references.bib` — BibTeX bibliography
- `figures/` — manuscript-ready PDF figures, with editable SVG and Mermaid (`.mmd`) sources

## Compile

The project is designed for **pdfLaTeX** with the `IEEEtran` document class. To compile locally:

```text
pdflatex main.tex
bibtex main
pdflatex main.tex
pdflatex main.tex
```

Or upload these tracked files to [Overleaf](https://www.overleaf.com), set `main.tex` as the main document, select pdfLaTeX, and recompile.

## Repository scope

This repository intentionally contains the editable manuscript source and figure assets only. Personal drafts, exported PDFs, Word files, previews, and temporary manuscript-generation tools are excluded.
