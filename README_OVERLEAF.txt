---------------------------
1. Go to https://www.overleaf.com and log in.
2. Click "New Project" -> "Upload Project".
3. Upload this ZIP file: "IEEE_Manuscript_Overleaf_Package.zip".
4. Ensure the main document is set to "main.tex" and compiler is "pdfLaTeX".
5. Click "Recompile".
